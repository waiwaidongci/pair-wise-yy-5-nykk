# 手工织锦纹样排版台

直接打开`index.html`使用。支持网格绘制、色线统计、撤销重做、本地保存和导出JSON。

## 离线补丁合并

织锦师傅可「送去离线工坊」（新标签页，基线版本与主站一致）离线改样，完成后「传回主站」或「生成补丁文件」。补丁带基线版本和改动格，合并时：

- 版本相同且本地未改的格 → 正常并入；
- 当前格已改（本地与补丁都改）或多份补丁改同一格 → 列入冲突，每色各留一份待选，选好后「确认并入」；
- 基线版本失效、格号或色号无效 → 跳过并提示；
- 合并失败或取消 → 从原图案恢复，可「恢复原图案并重试」；
- 确认后色线用量、重复单元预览、断线风险、保存和导出均按新图案重算；
- 撤销一次退回整批合并。
