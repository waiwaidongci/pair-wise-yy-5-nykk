# 手工织锦纹样排版台

直接打开`index.html`使用。支持网格绘制、色线统计、撤销重做、本地保存和导出JSON。

## 离线补丁合并

师傅可把图案带到断网工坊修改，再以色线补丁的形式带回合并：

1. 出发前点击「保存方案」，当前图案即记为基线版本。
2. 在工坊（可离线打开同一页面）改完后点「导出补丁」，得到 `brocade-patch-v*.json`。
3. 回站后点「导入图案/补丁」，可一次选择多份补丁文件，按顺序并入。

合并规则：

- 补丁基线版本与当前版本相同：直接并入。
- 版本不同：逐格比对。当前格相对基线未改则干净并入；当前格已改或两边都改过，该格保留「当前 / 补丁」两份待选，在右侧「补丁合并」面板逐格选择（网格中以双色斜分格标出）。
- 任一份补丁校验失败（尺寸不符、格子越界、色线编号未知等）：整批放弃并自动从原图案恢复，可修正后重新导入；「恢复原图重试」也可随时手动放弃本次合并。
- 「确认合并」后，用色统计、重复单元预览、断线风险、保存与导出均按新图案计算；整批合并只算一次撤销，点一次「撤销」即退回合并前。

补丁格式：

```json
{
  "pid": "abc123",
  "baseVersion": 4,
  "cols": 18,
  "rows": 14,
  "changes": [{ "i": 40, "from": 0, "to": 2 }]
}
```

`i` 为格子序号（行优先），`from` 为基线色线编号，`to` 为改后色线编号；`pid`、`cols`、`rows` 可选，用于校验防止误并。
